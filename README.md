# Домашнее задание №2: Cashback Merge

Описание задачи: [TASK.md](TASK.md)

## Запуск

Требуется Go 1.26.x. После `make install`:

```bash
make run ARGS="--config campaign.json --seed 341124"
```

CLI загружает конфигурацию и показывает начальное поле 4×4 из двух плиток.
По умолчанию seed равен `341124`; его можно изменить флагом `--seed`.
Пустая клетка обозначается точкой. При одинаковых конфигурации и seed поле одинаковое.
Ошибочная конфигурация завершает запуск с ненулевым кодом

## Конфигурация

Пример - [campaign.json](campaign.json). `cashback` хранится как целое число процентов,
вероятности - как точные рациональные числа `big.Rat`, без `float`

- `movesLimit` - положительный лимит валидных ходов.
- `spawnRules` - непустой список значений и вероятностей в интервале `(0, 1]` с точной суммой 1.
- `maxRewardCashback` - порог максимальной награды.
- `maxRewardAllowedRate` - допустимая доля максимальной награды в интервале `[0, 1]`.
- `rewards` - массив объектов `{"cashback": "1", "tier": "basic"}`:
  для каждой степени двойки от 1 до `maxRewardCashback` нужен ровно один непустой `tier`.

Значения плиток и порога награды - положительные степени двойки; ноль означает пустую клетку.
Порог награды не ограничивает значения появляющихся плиток.
Конфигурация также проверяется на безопасный диапазон `int` для плиток и score:
верхняя оценка `maxSpawn × (movesLimit + 2) × movesLimit` должна помещаться в `int`.

## Устройство

`internal/game` содержит модель поля, загрузку/валидацию конфигурации и генератор начального состояния.
`cmd/cashback-merge` отвечает за аргументы, чтение файла и вывод.

Появление плитки выделено отдельно: свободная клетка выбирается равномерно,
значение - по `spawnRules`. Веса приводятся к общему целому знаменателю.
случайный билет выбирается без округления вероятностей.

## Проверки

```bash
make format

```

Тесты проверяют конфигурацию, две начальные плитки, воспроизводимость по seed,
текстовый вывод, границы весов и запуск CLI. `make test` создаёт отчёт `coverage.html`.
